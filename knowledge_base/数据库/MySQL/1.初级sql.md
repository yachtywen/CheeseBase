# MySQL 数据库基础 - 第一课

## 一、CRUD 概念

| 操作 | SQL 命令 | 说明 |
|------|----------|------|
| **C**reate | INSERT | 插入数据 |
| **R**ead | SELECT | 查询数据 |
| **U**pdate | UPDATE | 更新数据 |
| **D**elete | DELETE | 删除数据 |

---

## 二、数据库和表的创建

### 1. 创建数据库
```sql
CREATE DATABASE 数据库名;
```

### 2. 进入数据库
```sql
USE 数据库名;
```

### 3. 创建数据表
```sql
CREATE TABLE 表名 (
    字段1 类型 PRIMARY KEY AUTO_INCREMENT,
    字段2 类型 NOT NULL,
    字段3 类型
);
```

### 4. 查看表结构
```sql
DESC 表名;
```
### 5. 新增字段
```sql
ALTER TABLE 表名 ADD 字段名 类型 [约束];
e.g.
ALTER TABLE students ADD email VARCHAR(100);
(添加带默认值的列)
ALTER TABLE students ADD gender VARCHAR(5) DEFAULT '未知';
```
---
### 6. 修改表结构
```sql
ALTER TABLE 表名 MODIFY 字段名 类型 [约束];
e.g.
ALTER TABLE students MODIFY age INT;

ALTER TABLE 表名 ADD PRIMARY KEY (列名);

```


## 三、插入数据 (INSERT)

```sql
-- 插入单条数据
INSERT INTO 表名 (字段1, 字段2, 字段3) VALUES ('值1', 值2, '值3');

-- 插入多条数据
INSERT INTO 表名 (name, age, grade) VALUES 
('张三', 20, '大一'),
('李四', 22, '大三'),
('王五', 19, '大一');
```

---

## 四、查询数据 (SELECT)

### 基础查询
```sql
-- 查询所有数据
SELECT * FROM 表名;

-- 查询指定列
SELECT 字段1, 字段2 FROM 表名;
```

### 条件查询
```sql
-- WHERE 条件筛选
SELECT * FROM 表名 WHERE age > 20;

-- 精确匹配
SELECT * FROM 表名 WHERE grade = '大一';

-- 模糊查询（% 匹配任意字符）
SELECT * FROM 表名 WHERE name LIKE '张%';
```

### 排序
```sql
-- ASC 升序（从小到大，默认）
SELECT * FROM 表名 ORDER BY age ASC;

-- DESC 降序（从大到小）
SELECT * FROM 表名 ORDER BY age DESC;

- ORDER BY 后面有多个列时，从左到右依次优先排序
- 只有当前面的列 值相同 时，才会看后面的列
```

| 关键字 | 含义 |
|--------|------|
| ASC | 升序（1, 2, 3...） |
| DESC | 降序（3, 2, 1...） |

### 去重查询
```sql
-- DISTINCT 关键字
SELECT DISTINCT 字段1, 字段2 FROM 表名;
```
---

## 五、更新数据 (UPDATE)

```sql
-- 更新单个字段
UPDATE 表名 SET 字段1 = '新值' WHERE 条件;

-- 更新多个字段
UPDATE 表名 SET 字段1 = '新值1', 字段2 = '新值2' WHERE 条件;

-- 示例
UPDATE students SET age = 21 WHERE name = '张三';
UPDATE students SET age = 23, grade = '大四' WHERE name = '李四';
```

> ⚠️ **注意**：使用 UPDATE 时务必加 WHERE 条件，否则会更新整张表！

---

## 六、删除数据 (DELETE)

```sql
-- 按条件删除
DELETE FROM 表名 WHERE 条件;

-- 示例
DELETE FROM students WHERE name = '王五';

-- 删除表中所有数据（谨慎！）
DELETE FROM 表名;
```

> ⚠️ **注意**：使用 DELETE 时务必加 WHERE 条件，否则会删除表中所有数据！

---

## 七、DROP 命令（慎用）

| 命令 | 作用 | 数据是否可恢复 |
|------|------|----------------|
| `DELETE FROM 表名` | 删除表中数据，表还在 | 可恢复（需备份） |
| `DROP TABLE 表名` | 删除整张表 | **不可恢复** |
| `DROP DATABASE 库名` | 删除整个数据库 | **不可恢复** |

## 附加的基本运算

### 1. 多个表的关系运算笛卡尔积
```sql
SELECT * FROM 表1, 表2;

select * from table1 join table2 on table1.id = table2.id;
```
### 2. 更名运算
```sql
SELECT 字段1 AS 新字段1, 字段2 AS 新字段2 FROM 表名;
```
### 3. 字符串运算
```sql
like '值%' -- 匹配以值开头的字符串
like '%值%' -- 匹配包含值字符串
like '_值_' -- 匹配中间字符是值的任意含有三个字符的字符串
e.g.
SELECT * FROM 表名 WHERE name LIKE '张%'; -- 匹配以张开头的姓名
SELECT * FROM 表名 WHERE name LIKE '%三'; -- 匹配姓名中包含三的
```
### 4.集合运算
```sql
(行拼接)
UNION -- 合并两个结果集（会去重）速度慢
UNION ALL -- 合并两个结果集，并保留重复的行
intersect -- 交集
except -- 差集
```
### 5. 聚合函数
```sql
COUNT(*) -- 统计行数
SUM(字段) -- 求和   
AVG(字段) -- 平均值
MAX(字段) -- 最大值
MIN(字段) -- 最小值
```
### 6. 分组聚集
```sql
SELECT 字段1, 字段2, SUM(字段3) AS 总数 FROM 表名 GROUP BY 字段1, 字段2;
```
### 7.having子句
```sql
SELECT 字段1, 字段2, SUM(字段3) AS 总数 FROM 表名 GROUP BY 字段1, 字段2 HAVING 总数 > 10;
```
### 8. 子查询
```sql
SELECT * FROM 表名 WHERE 字段1 IN (SELECT 字段1 FROM 表名2 WHERE 条件);
SELECT * FROM 表名 WHERE 字段1 NOT IN (SELECT 字段1 FROM 表名2 WHERE 条件);
```
### 9. exists子句
```sql
--EXISTS 用于 检查子查询是否返回至少一行记录 ，返回 TRUE 或 FALSE 。
SELECT * FROM 表名 WHERE EXISTS (SELECT * FROM 表名2 WHERE 条件);
```
### 10. some关键字
```sql
--SOME 是 比较运算符 ，用于将一个值与子查询返回的 任意一个值 进行比较。等价于 ANY 。
SELECT * FROM 表名 WHERE 字段1 > SOME (SELECT 字段1 FROM 表名2 WHERE 条件);
```
### 11. join 连接
```sql
-- 内连接
--inner join=join=natural join
--只保留两者匹配成功的内容，不匹配的行将被删除。
SELECT 表1.字段1, 表1.字段2, 表2.字段3 FROM 表1 INNER JOIN 表2 ON 表1.字段1 = 表2.字段1;
--左外连接
--left join=left outer join
--保留左表所有行（未匹配成功的用NULL填充），右表匹配成功的行。
--右外连接（同上原理）
-- 外连接（全外连接）两边都保留，不管是否匹配成功。
SELECT 表1.字段1, 表1.字段2, 表2.字段3 FROM 表1 LEFT JOIN 表2 ON 表1.字段1 = 表2.字段1;
SELECT 表1.字段1, 表1.字段2, 表2.字段3 FROM 表1 RIGHT JOIN 表2 ON 表1.字段1 = 表2.字段1;
SELECT 表1.字段1, 表1.字段2, 表2.字段3 FROM 表1 FULL JOIN 表2 ON 表1.字段1 = 表2.字段1;
--自然连接（有危害尽量不用）
--natural join=equijoin=join on common columns
--自动匹配两表中相同的列，并将两表中相同的列作为连接条件。
SELECT 表1.字段1, 表1.字段2, 表2.字段3 FROM 表1 NATURAL JOIN 表2;
```
