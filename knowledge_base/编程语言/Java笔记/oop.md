# Java Object-Oriented Programming

Java is built around classes, objects, interfaces, inheritance, and
polymorphism.

Core ideas:

- Encapsulation hides implementation details behind methods.
- Inheritance reuses behavior from a parent class.
- Interfaces describe capabilities without fixing implementation.
- Polymorphism allows code to depend on abstractions.

Compared with Rust traits, Java interfaces are runtime-oriented and commonly
used with reference types. Rust traits can be combined with generics and static
dispatch to express similar abstractions with different performance tradeoffs.
